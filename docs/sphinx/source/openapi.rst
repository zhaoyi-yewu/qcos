OpenAPI接口规范
======================

本章节提供基于 FastAPI 自动生成的 OpenAPI 交互式文档（ReDoc）。

ReDoc 文档为自包含 HTML，内嵌完整的 OpenAPI Spec 和 ``redoc.standalone.js``，
支持在线浏览和搜索所有 API 接口的请求参数、响应格式和数据模型。

    以下通过 iframe 嵌入 ReDoc 页面。如果无法正常显示，可点击下方链接
    在新窗口中打开完整 API 文档。
