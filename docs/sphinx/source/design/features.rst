整体功能
===========

量子计算操作系统(QCOS)的功能、亮点和未来计划主要有:

功能
--------
- 支持北向API、命令行、SDK、Web界面等多种管理方式
- 支持作业提交、状态查询、结果查询、取消、删除和回调功能
- 支持多任务，以及任务的管理和优先级调度
- 支持心跳检测、版本能力查询
- 支持QASM解析、量子比特映射、量子门分解、编译与优化功能
- 支持驱动框架管理器，实现驱动自动发现、注册与配置加载
- 支持测试驱动(dummy)、中性原子驱动、光量子驱动、超导驱动、离子阱驱动
- 支持多后端量子设备同时操作
- 支持量子计算机模拟器
- 支持作业聚合、作业拆分
- 支持量子错误缓解(QEM)【计划】、量子纠错(QEC) 【计划】
- 支持自动化校准 【计划】
- 支持运维、监控、告警 【计划】
- 支持热升级 【计划】

亮点
--------
- 量子计算多任务并发、或者排队
- 支持多种路线、多种类型的量子计算机。包括：中性原子、离子阱、超导、光量子、核磁等
- 自定义驱动，厂商解耦
- 测控对接能力
