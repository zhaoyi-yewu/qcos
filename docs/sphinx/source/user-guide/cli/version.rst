版本命令
----------------------

版本命令用于查询服务端的版本信息和支持能力。

版本查询
***************

查询服务端版本信息

命令行参数
~~~~~~~~~~~~~~~

.. code-block:: shell

   # 查询服务端版本
   usage: qcos-cli version [-h]

   Get server version and capabilities.

   options:
     -h, --help            show this help message and exit

典型场景示例
~~~~~~~~~~~~~~~

.. code-block:: shell

   # 查询服务端版本
   qcos-cli version
